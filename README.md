# ASA SERVER 공식 위키

2026년 11월 11일 로비와 프록시 배포본을 반영한 한국어 플레이 가이드입니다. 처음 입장하면 배경음악을 켜거나 조용히 입장할 수 있습니다.

## GitHub Pages에 적용하기

1. ZIP을 새 폴더에 풉니다. 압축 안에 있는 `index.html`, `.nojekyll`, `assets/`, `pages/`와 나머지 파일을 함께 선택하세요.
2. GitHub에서 기존 Pages 게시 폴더를 열고 **Add file → Upload files**에 선택한 내용을 끌어다 놓은 뒤 **Commit changes**를 누릅니다. 압축 안의 파일은 총 71개입니다. 루트에서 게시한다면 저장소 첫 화면에 `index.html`이 보여야 합니다.
3. 배포가 끝나면 사이트의 **상점 상품 찾기**에서 ‘거친 호박석’을 검색하세요. 1개 판매가가 36원이고 64개 판매 금액이 2,304원이면 이번 판이 적용된 것입니다.

로컬 미리보기는 압축을 풀고 `index.html`을 열면 됩니다. 사용 중인 주소 뒤에 아래 경로를 붙여 해당 화면을 공유할 수 있습니다.

| 화면 | 주요 기능 |
| --- | --- |
| `#quick` | 메뉴·NPC 경로 30개와 상점가 NPC 7명의 위치. `#quick?path=shop-miner`에서 광부 브론의 대화 선택과 거래 순서를 봅니다. |
| `#commands?frequent=1` | 자주 쓰는 플레이어 명령 27개. 화면에서 진행할 수 있는 기능에는 실제 메뉴·NPC 이용 경로를 연결했습니다. |
| `#commands` | 기본 명령 522개, 세부 구문 2,155개, 입력 예시 144개. 검색, 플러그인·서버별 필터, 즐겨찾기, 복사, 링크 공유, 전체 TXT 다운로드가 가능합니다. 관리자·콘솔 전용 항목에는 대상과 권한이 표시됩니다. |
| `#mining?tier=1` | 호박석에서 루비스까지 16단계, 채굴 가능한 최소 곡괭이와 다음 제작 재료, 광맥 높이·확률·크기, 도구 내구도와 추가 드롭, 특수광물 거래가를 확인합니다. |
| `#market` | 16개 상점의 상품 설정 784건. 검색과 거래 필터로 구매·판매 단가, 수량별 금액, 원·캐시 구분과 확인된 NPC 대화 경로를 봅니다. |
| `#jobs` | 직업 22개의 스킬 132종, 해금 레벨, 패시브·액티브·각성 구분. 내 레벨을 입력하면 다음 기술을 표시합니다. |
| `#legacy` | 게임 화면의 세부 경로와 이전 위키 기록 44개. 지난 안내는 현재 확인 상태와 함께 볼 수 있습니다. |

통합 검색은 상단 검색 버튼이나 Ctrl+K(맥은 ⌘K)로 엽니다. NPC, 메뉴, 상품, 직업, 스킬, 광물 또는 명령어를 입력한 뒤 화살표 키와 Enter로 이동합니다. 즐겨찾기와 보유 곡괭이는 사용 중인 브라우저에 저장됩니다.

## 자료 기준

- 로비 Paper 82개와 Velocity 12개 플러그인 JAR의 등록 정보와 실행 코드, 함께 전달된 설정을 사용했습니다. 권한, 초대·소속 상태, 운영 중 변경된 설정에 따라 게임에서 이용할 수 있는 기능이 달라질 수 있습니다.
- NPC 위치는 Citizens, 상점 대화·휠 선택·F 확정은 LuxDialogues, 메뉴 버튼은 DeluxeMenus, 상품과 거래 조작은 AsaShop을 대조했습니다. 상품은 784건 중 765건에서 한 방향 이상 거래가 켜져 있습니다. 대화에서 입구를 확인한 상점 분류는 10개입니다. 게임 상점은 금액을 정수로 표시하고 위키는 소수점 단가를 보여 줍니다.
- 이번 로비 자료에는 광물 생성 규칙 53개가 있습니다. 야생에서는 이전에 제공된 11월 10일 야생 설정의 64개 규칙을 참고합니다. 도감에서 자료를 선택하면 11월 11일 로비 설정에 등록되지 않은 변형도 구별할 수 있습니다.
- 직업과 스킬은 AsaJobsReborn, 광물과 도구는 ItemsAdder 및 AsaOreTools의 항목을 따릅니다. 계정 데이터나 운영용 설정 파일은 배포할 필요가 없습니다.

## 파일 수정

`index.html`에 본문과 광물·상품·직업의 공개 데이터가 있습니다. 공통 탐색과 검색은 `assets/app.js`, 화면별 동작은 `assets/field-guide.js`, `assets/player-routes.js`, `assets/mining-guide.js`, `assets/wiki-commands.js`에서 변경합니다. 명령어 데이터를 바꾸면 `assets/wiki-command-data.js`와 `assets/downloads/ASA_Commands.txt`를 함께 갱신하세요. 화면 스타일을 수정한 뒤에는 해당 CSS·JS 주소의 버전 값도 갱신하세요.
