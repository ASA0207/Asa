# 육각수 · HEXAWATER

**함께할수록 선명해지는 우리.**  육각수 길드 홍보용 프리미엄 정적 웹사이트입니다.

> 별도 서버, 데이터베이스, Node.js 설치가 필요하지 않습니다. GitHub Pages에 파일을 그대로 배포하면 됩니다.

## 1. GitHub Pages 배포 방법

1. 전달받은 ZIP의 압축을 해제하세요.
2. GitHub에서 새 저장소를 만들거나, 기존 홍보 페이지 저장소를 여세요.
3. 이 폴더 안의 `index.html`, `styles.css`, `script.js`, `config.js`, `sw.js`, `manifest.webmanifest`, `assets/` 및 `.nojekyll`을 **저장소 최상위(루트)** 에 업로드하세요. `YUKGAKSU_GITHUB_PAGES` 폴더 자체를 한 겹 더 올리지 마세요.
4. GitHub의 **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main → Folder: /(root) → Save**를 선택합니다.
5. GitHub가 표시하는 공개 주소로 사이트를 열어 보세요.

저장소 주소가 `아이디.github.io`이면 보통 `https://아이디.github.io/`, 일반 저장소가 `yukgaksu`이면 보통 `https://아이디.github.io/yukgaksu/`로 공개됩니다. 상대 경로를 사용하므로 어느 쪽에도 대응합니다.

## 2. NEW · 시작화면 배경음악 및 플레이어

**추가한 음원**: 보내주신 `IVE – REBEL HEART` MP3 (185초 / 320kbps / 7.1MB). 오디오가 `/assets/rebel-heart.mp3`에 포함되어 있습니다. 별도로 유튜브/스포티파이 링크를 연결할 필요가 없습니다.

1. 처음 사이트를 열면 길드 전용 인트로 화면이 표시됩니다.
2. **노래와 함께 입장**: 클릭을 계기로 음악을 재생하고 메인 홍보 페이지로 진입합니다. 첫 재생은 기본 음량 **22%**에서 부드럽게 시작됩니다.
3. **조용히 입장하기**: 음악 다운로드와 자동 재생 없이 사이트에 진입합니다.
4. 진입 후 왼쪽 아래 **REBEL HEART 음악 플레이어**로 재생/일시정지, 음소거/해제, 0~100% 음량 슬라이더를 조절할 수 있습니다.
5. 사용자가 선택한 음량만 브라우저 저장소에 유지됩니다. 새로고침하면 **시작화면이 다시 표시되고**, 선택 없이 음악을 자동으로 켜지 않습니다.

오디오를 재생하려면 사용자가 버튼을 직접 눌러야 합니다. 이는 Chrome, Safari, 모바일 브라우저의 자동재생 정책을 지키기 위한 것입니다. 일부 사용자는 기기 무음 모드, 사이트별 오디오 제한 또는 통신 상태에 따라 재생이 제한될 수 있습니다.

**음원을 바꾸려면** 같은 이름의 `assets/rebel-heart.mp3`를 다른 음원으로 교체하고 `index.html`의 곡 제목 및 `script.js`의 `MediaMetadata`를 수정하세요. 기본 볼륨은 `script.js`의 `return 22;`와 `index.html`의 `value="22"`를 변경하면 됩니다. MP3는 오프라인 사전 캐시 대상에서 제외되므로 조용히 입장하는 방문자가 7MB를 다운로드하지 않습니다.

> **저작권 주의**: 첨부해주신 음원을 요청에 따라 사이트에 포함했습니다. 공개 GitHub Pages에 곡을 업로드해 누구나 들을 수 있게 하는 것은 별도 음악 배포/공중송신 허락이 필요할 수 있습니다. 원곡 저작권자와 음원 권리자로부터 적절한 사용 권한을 확인한 뒤 공개 배포하세요. 원본 파일 소유나 출처 표기만으로 웹 공개 허락이 생기지는 않습니다.

## 3. 가입 문의 버튼 연결하기 (중요)

육각수 규칙에는 **디스코드 초대 링크의 외부 공개와 무단 초대를 금지**한다고 적혀 있습니다. 따라서 안전을 위해 초대 링크를 웹사이트에 넣지 않았습니다.

`config.js`를 열고 다음 값을 **외부 공개가 허용된 가입 문의 링크**로 교체해 주세요. 예: 공개 신청 폼, 공개 상담 채널.

```js
window.HEXAWATER_CONFIG = Object.freeze({
  recruitmentUrl: "https://여기에-공개-가입-문의-주소",
  recruitmentLabel: "가입 문의"
});
```

- 실제 URL을 등록하기 전에는 모든 `가입 문의` 버튼을 클릭했을 때 **안내 팝업**이 열립니다. 작동하지 않는 가짜 링크는 없습니다.
- 공개 홈페이지에 **비공개 디스코드 초대 링크를 넣지 마세요.**
- 버튼을 외부 가입 폼/상담 채널로 연결할 경우, 사용자는 새 탭으로 이동합니다.

## 4. 홍보 정보 수정하기

`index.html`에서 텍스트를 검색해 변경하면 됩니다.

| 내용 | 수정 위치 |
| --- | --- |
| 길드 이름·소개·SEO 문구 | `index.html`의 `<head>`와 HERO 섹션 |
| 길드 가치 6가지 | `id="about"` 섹션 |

**중요:** 카운트다운은 한국 시간(KST) **매일 22시**를 기준으로 동작합니다. 시간을 변경하려면 `index.html`의 일정 표시 텍스트와 함께 `script.js`의 `22 - 9` 부분(22시 KST 기준 UTC 계산)을 새 시간에 맞게 바꾸세요.

## 5. 공유 이미지 (카카오톡·디스코드 등)

`assets/og-cover.png`는 1200×630으로 제작한 전용 공유 이미지입니다.

GitHub Pages에 배포한 뒤 `index.html`의 다음 항목을 **실제 사이트를 기준으로 하는 절대 URL**로 바꾸는 것을 권장합니다.

```html
<meta property="og:image" content="https://아이디.github.io/저장소명/assets/og-cover.png">
```

현재는 `assets/og-cover.png`라는 상대 주소로 넣어 두었습니다. 사이트 내 표시에는 영향이 없으나, 링크 미리보기 서비스는 절대 URL을 요구할 수 있습니다.

## 6. 포함된 기능

- 사용자 선택형 인트로 (음악과 함께 입장 / 조용히 입장), 반응형 프리미엄 입장 화면
- REBEL HEART MP3 포함, 22% 기본 음량·부드러운 시작·재생·음소거·볼륨 슬라이더
- 육각수 전용 육각형 크리스털/물결 SVG 그래픽 (외부 이미지 의존 없음)
- 데스크톱·태블릿·모바일 완전 반응형 레이아웃
- 스크롤 진입 연출, 육각형 캔버스 파티클, 인터랙티브 카드
- 움직임 줄이기 버튼 및 OS 모션 축소 설정 지원
- 현재 위치 표시 네비게이션, 모바일 메뉴, 맨 위로 이동, 스크롤 진행도
- 전체 길드 규칙 펼치기/접기, 키보드 접근 가능한 상세 규칙 및 FAQ
- 한국 표준시 기준 길드 퀘스트 카운트다운
- 가입 문의 안내 팝업, 공개 문의 링크 설정
- 모바일 공유 시트 또는 주소 복사 버튼
- SNS 공유용 이미지, Open Graph 메타, 파비콘
- 서비스 워커 기반 정적 파일 오프라인 캐시 및 앱 아이콘
- 별도 서버/API 없이 구동, 계정·쿠키·개인정보를 자체 수집하지 않음

## 7. 운영·최적화 안내

- 첫 접속 시 외부 Google Fonts가 로딩될 수 있지만, 실패해도 시스템 폰트로 정상 표시됩니다.
- 오프라인 캐시가 구버전을 보여 주는 경우에는 `sw.js` 상단의 `VERSION` 문자열을 변경한 뒤 재배포하세요 (예: `hexawater-v1.0.1`).
- `assets/` 폴더와 `index.html`의 상대 경로를 유지하세요.
- 날짜/일정과 규칙은 운영 방침 변경 시 업데이트해야 합니다. 카운트다운은 공지 변경을 자동으로 감지하지 않습니다.
- 제공된 음원을 그대로 포함하되, 허락 없는 공개 배포는 저작권 문제가 발생할 수 있습니다.
- 오디오는 오프라인 사전캐시에 포함되지 않아 방문자가 조용히 입장하는 경우 다운로드하지 않습니다.
