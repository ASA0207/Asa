# ASA SERVER 공식 위키

마인크래프트 ASA 서버의 플레이 가이드입니다. 위키의 첫 화면에서 메뉴·NPC 이용 방법, 전체 명령어 백과, 광물 도감을 바로 열 수 있습니다.

## GitHub Pages에 올리기

1. **새 폴더에 ZIP을 풀고** `index.html`, `.nojekyll`, `assets/`, `pages/` 등 압축 안의 내용을 기존 Pages 게시 폴더에 함께 넣습니다. 루트에서 게시하는 저장소라면 `index.html`이 저장소 첫 화면에 바로 보여야 합니다.
2. GitHub 웹에서 올릴 때는 기존 게시 폴더에서 **Add file → Upload files**를 선택합니다. 압축을 푼 폴더 안의 파일과 하위 폴더를 함께 드래그하고 **Commit changes**를 누릅니다. 이 배포본에는 파일이 68개 있습니다. 기존 게시 브랜치에 변경 내용을 커밋합니다. 새로 설정하는 경우 저장소의 **Settings → Pages**에서 **Deploy from a branch**와 게시 브랜치, 해당 폴더를 선택합니다.
3. 배포가 완료되면 사이트 주소 끝에 `#quick`, `#commands`, `#mining?tier=1`을 붙여 각 화면을 열 수 있습니다. 원래 위키의 `pages/*.html` 주소도 해당 가이드로 연결됩니다.

로컬 미리보기는 압축을 푼 뒤 `index.html`을 브라우저로 열면 됩니다. 검색과 도감의 데이터, 그림, 배경음악이 ZIP에 포함됩니다.

## 플레이어용 화면

| 화면 | 이용 방법 |
| --- | --- |
| `#quick` 메뉴·NPC 이용 가이드 | 게임 메뉴와 같은 배열로 상점·스폰·마을·연못·내정보·창고를 찾습니다. 목적별 경로 28개를 NPC 이름이나 기능으로 검색할 수 있습니다. 예를 들어 `#quick?path=shop-miner`는 광부 브론의 대화 선택과 광물 거래를 바로 엽니다. |
| `#commands?frequent=1` 자주 쓰는 명령어 | 일반 플레이어용 27개를 모았습니다. 화면으로도 할 수 있는 기능은 해당 명령의 상세 내용에서 메뉴·NPC 이용 경로로 이동할 수 있습니다. |
| `#commands` 명령어 백과 | 기본 명령 517개와 세부 사용 구문 2,158건을 검색합니다. 명령을 펼치면 별칭, 확인된 권한, 근거 파일, 등록 정보와 입력 예시를 볼 수 있습니다. 검색 필터, 저장, 구문 복사, 개별 링크와 전체 목록 TXT 다운로드를 지원합니다. |
| `#mining` 광물 도감 | 16단계 채굴 순서와 최소 도구를 확인합니다. 보유 곡괭이를 선택하거나 광물 카드에서 일반석·심층암·네더·엔드를 전환해 높이, 생성 확률, 광맥 크기를 봅니다. 각 광물에는 곡괭이 제작법과 특수광물 상점 정보가 있습니다. |
| `#legacy` GUI 이용 경로 | NPC 대화와 메뉴로 이용하는 세부 화면 안내 38개와 기존 위키에 적힌 안내 6개가 있습니다. 이전 기록의 확인 상태를 함께 표시합니다. |

상단 검색 버튼이나 `Ctrl+K`(Mac은 `⌘K`)로 문서·NPC·메뉴·명령어·광물을 함께 찾습니다. 화살표 키로 이동하고 Enter로 결과를 엽니다. 즐겨찾기와 보유 곡괭이 선택은 사용 중인 브라우저에 저장됩니다.

## 데이터 기준과 수정 위치

- 메뉴 위치와 표시명은 10월 14일의 `asamenu.yml`·`asainfo.yml`을 기준으로 했습니다. 상인 이름과 선택지는 11월 10일의 LuxDialogues 대화와 상점 연동 설정, 화면 안의 거래 동작은 AsaShop 실행 코드를 기준으로 했습니다. 퀘스트 NPC는 담당 역할로 표기했습니다.
- 명령어는 로비 Paper 76개, Velocity 프록시 11개 JAR의 등록 정보·명령 처리 코드·기본 리소스에서 확인했습니다. 백과에는 관리자·콘솔용 항목도 포함됩니다. 실제 사용 권한과 단축어 우선순위는 운영 서버 설정에 따라 달라집니다.
- 광물은 ItemsAdder 채굴 허용 도구와 3차원 생성 설정을 기준으로 정렬했습니다. 도감의 확률은 설정에 기재된 광맥 생성 확률입니다. 추천 차원 외에서도 해당 변형의 생성 설정이 적용됩니다.
- `index.html`에는 본문, 메뉴, 자주 쓰는 명령어, 광물 데이터와 GUI 안내가 있습니다. 전체 명령 데이터는 `assets/wiki-command-data.js`, 텍스트 다운로드는 `assets/downloads/ASA_Commands.txt`에 있습니다. 명령 데이터를 수정할 때는 두 파일을 함께 갱신합니다.
- `assets/app.js`는 화면 이동, 통합 검색과 음악을 담당합니다. 메뉴·NPC 경로 검색과 개별 경로 열기는 `assets/player-routes.js` 및 `assets/player-routes.css`에 있습니다. 다른 기능의 코드는 `assets/wiki-commands.js`, `assets/mining-guide.js`, `assets/wiki-legacy.js`에 있으며, 화면 스타일은 같은 이름의 CSS 및 `assets/wiki-shell.css`에 있습니다. 광물 상세 화면은 `index.html`의 `mine-data` 안에 PNG 원본을 포함합니다. 초기 화면 및 광물 목록 아이콘은 `assets/ores/`에 있습니다.
