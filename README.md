# ASA SERVER WIKI

GitHub Pages용 정적 위키 템플릿입니다.

## 배포
1. GitHub에 새 repository를 만듭니다.
2. 이 폴더 안의 파일을 repository 최상위에 업로드합니다.
3. Settings → Pages → Build and deployment에서 **Deploy from a branch** 선택.
4. Branch를 `main`, 폴더를 `/(root)`로 선택하고 Save.
5. 잠시 후 GitHub Pages 주소가 생성됩니다.

## 수정
- `index.html`: 홈
- `pages/`: 각 위키 문서
- `assets/css/style.css`: 디자인
- `assets/js/app.js`: 모바일 메뉴/간단 검색
