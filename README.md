## GitHub에 적용하기

1. 기존 Asa 저장소를 ZIP으로 내려받아 별도로 보관하세요.
2. 이 배포 ZIP을 새 폴더에 풉니다. 압축파일 자체를 GitHub에 올리지 마세요.
3. 기존 위키가 게시되는 폴더에 index.html, assets, pages, .nojekyll, 404.html, sitemap.xml, robots.txt, README.md를 함께 올려 덮어씁니다.
   기존처럼 저장소 루트에서 게시한다면 루트에 index.html이 보여야 합니다. 폴더 한 겹이 더 들어가지 않도록 주의하세요.
   GitHub 웹에서는 Add file → Upload files로 압축 해제한 파일과 폴더를 올린 뒤 Commit changes를 누릅니다.
4. 저장소의 기존 Pages 설정을 유지하고 배포 완료를 기다립니다. 별도 Node 설치나 빌드 명령은 필요하지 않습니다.
5. 기존 위키 주소에서 Ctrl+F5로 새로고침하세요. 홈에 ‘아사 생활의 모든 것.’, 아래에 ‘2026.11.25 검토 자료’가 보이면 새 화면입니다.

게임 서버 재시작·iazip·런처 업데이트는 필요하지 않습니다. 서버 설정·잔액·아이템은 이 웹사이트 배포로 변경되지 않습니다.
기존의 쓰지 않는 CSS/JS/음악 파일은 새 화면이 참조하지 않습니다. 기존 별도 다운로드 링크 ASA_Commands.txt는 새 플레이어 명령어 목록으로 교체합니다.
